# Membexa

Membexa is a WordPress membership and subscription plugin built with WordPress-native administration patterns, plan-based content access, member accounts, and Stripe-hosted Checkout.

## Status

Version 1.0.0 development candidate. The `develop` branch is used for review before merging a release to `main`.

## Requirements

- WordPress 6.4+
- Tested with WordPress 7.1
- PHP 7.4+

## Development

Runtime code has no Composer dependency. Composer is used only for development tooling.

```bash
composer install
composer lint
composer phpcs
```

## Security

Please report security issues privately to the maintainer rather than opening a public exploit report.
